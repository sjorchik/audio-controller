# Аудіоконтролер на ESP32-S3

Проєкт аудіоконтролера на базі:

- ESP32-S3-N16R8:
  - 16 MB QIO flash;
  - 8 MB octal PSRAM;
- селектор входів TDA7318 по I2C;
- АЦП PCM1808 по I2S;
- DSP всередині ESP32-S3;
- ЦАП PCM5102 по I2S;
- дисплей 1.9" IPS ST7789 170x320 по SPI;
- енкодер з кнопкою;
- 6 кнопок;
- IR-приймач VS1838B, протокол RC5;
- Wi-Fi STA + AP/captive portal у майбутньому;
- Web UI українською.

## Платформа

- Тільки ESP-IDF.
- Без Arduino.
- Збірка через PlatformIO.

## Апаратні вимоги (специфікація v2.2)

- PCM5102 XSMT = GPIO45; обов'язковий зовнішній pulldown 10 kOhm: тримає mute,
  поки ESP32 у reset або GPIO не ініціалізований. Модуль PCM5102 не повинен
  мати конфліктної підтяжки XSMT до VCC.
- GPIO22-25 не використовуються і не можуть використовуватися: не розведені
  на ESP32-S3-WROOM-1.
- Тактування I2S: ESP32-S3 - master, fs = 48 kHz; BCLK(GPIO15) = 64*fs;
  WS(GPIO17) = fs; MCLK(GPIO16) = 256*fs лише на SCKI PCM1808; PCM5102 SCK - NC/GND.
- Формат обох мікросхем - I2S; strap-піни FMT/DF перевірити за даташитами модулів.
- Власник XSMT - виключно компонент power: unmute лише після готовності аудіо.
