-------------консоль-------------
pio run -t menuconfig

ввімкнути передачу уарт / APP_DEV_CONSOLE

вибрати аудіопроц / APP_SELECTOR_CHIP

Перемикання орієнтації: runtime — lcdtest orient 1 1 0 / lcdtest orient 1 0 1; 
для збірки під монтаж — pio run -t menuconfig → Audio controller UI → Display mounting orientation.
