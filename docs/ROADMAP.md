## Критерії приймання

### Пункт 1. audio-A

1. Прямий прохід чутно: сигнал подано НАПРЯМУ на PCM1808 (в обхід TDA7318), чутно на виході PCM5102
2. Немає клацань при start/stop і BOOT-unmute
3. 10 хв прогону: underrun=0, overrun=0
4. DMA-буфери підтверджено в internal RAM (heap_caps-перевірка в лозі)
5. Такти: MCLK 12.288 MHz, BCLK 3.072 MHz, WS 48 kHz
6. CPU load задачі audio < 20% core 1
7. Коміт за конвенцією

### Пункт 2. audio-B

1. АЧХ 10-смугового EQ збігається з розрахунковою (±0.5 dB на центральних частотах смуг)
2. Гучність -90…0 dB працює, ramp без zipper-шуму
3. Лімітер працює при перевантаженні (вхід > 0 dBFS → вихід < -1 dBFS)
4. DC-blocker прибирає постійну складову
5. CPU load задачі audio < 40% core 1 з урахуванням DSP
6. Коміт за конвенцією

### Пункт 3. tda7318

1. Перемикання джерел працює на всіх 4 входах
2. Немає клацань при перемиканні (mute-перед-переключенням + пауза 20–50 мс)
3. I2C-комунікація стабільна (без зависань за 10 хв опитування)
4. Коміт за конвенцією

### Пункт 4. input

1. Кнопки: debounce працює, хибних спрацювань немає
2. Енкодер: PCNT рахує кроки, напрям визначається правильно на обох швидкостях обертання
3. Short/long press працюють
4. Події потрапляють у шину system
5. Коміт за конвенцією

### Пункт 5. ui

1. Дисплей ініціалізується, зображення стабільне без артефактів
2. Підсвітка регулюється через LEDC PWM
3. Фаза 5.1: базові екрани відображають джерело, гучність, стан
4. Фаза 5.2: LVGL працює, сторінки Main/Source/EQ/Settings/Info відображаються і перемикаються
5. У STANDBY дисплей і підсвітка вимкнені
6. Коміт за конвенцією

### Пункт 6. ir

1. RC5-коди декодуються правильно (перевірка відомим пультом)
2. Режим навчання працює: захват коду → прив'язка дії → збереження в NVS → переживає reboot
3. RC5-repeats обробляються коректно (vol± з repeat, решта без хибних повторів)
4. Коміт за конвенцією

### Пункт 7. web

1. Wi-Fi STA підключається до збереженої мережі, авто-реконект працює
2. AP captive portal працює при першому старті та втраті мережі
3. mDNS (audioctrl.local) резолвиться
4. HTTP REST API повертає актуальний стан пристрою
5. WebSocket синхронізує стан у реальному часі між браузером і пристроєм
6. Web UI повністю українською
7. Коміт за конвенцією

### Пункт 8. power/state

1. BOOT: XSMT mute від подачі живлення до готовності pipeline; unmute тільки після audio_pipeline_start
2. RUN → STANDBY: ramp down → XSMT mute → TDA mute → backlight off → Wi-Fi off → esp_pm знижує частоту
3. STANDBY → RUN: wake тільки POWER-кнопка або RC5-power; усі інші події ігноруються на рівні фільтра
4. ERROR: детект I2C/I2S fail, mute, індикація, спроба самовідновлення
5. Струм у STANDBY вимірювано нижчий за RUN
6. Коміт за конвенцією

### Пункт 9. settings

1. Налаштування зберігаються в NVS і переживають reboot
2. Версіонування конфігурації працює (міграція при зміні структури)
3. Відкладений запис працює (debounce проти зносу flash)
4. Factory reset повертає заводські значення
5. Коміт за конвенцією

### Пункт 10. tests

1. Юніт-тести DSP: коефіцієнти EQ, ramp, лімітер
2. Юніт-тести IR-декодера RC5
3. Інтеграційні перевірки повного тракту на залізі
4. Регресійний гейт перед кожним наступним комітом
5. Коміт за конвенцією
